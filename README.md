# MANIPULA Telegram Mini App

Статичный MVP мини-приложения для Telegram. Запись ведёт в действующую форму YCLIENTS: `https://b776703.yclients.com/`.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер из этой папки. Для публикации достаточно разместить содержимое папки на HTTPS-хостинге и указать итоговый URL в настройках бота через BotFather.

## Перед запуском

1. В BotFather создайте Menu Button или Inline Keyboard кнопку типа `web_app` с HTTPS-адресом приложения.
2. Убедитесь, что домен указан в настройках бота.
3. После подтверждения URL у Telegram пользователи смогут открыть приложение из бота.

Для полноценного раздела «Мои записи» потребуется серверная интеграция с API YCLIENTS: нельзя безопасно вызывать API с ключом из браузера.
